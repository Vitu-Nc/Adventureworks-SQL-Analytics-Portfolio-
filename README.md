# AdventureWorks SQL Analytics Portfolio

SQL analysis project using Microsoft's AdventureWorks2019 sample database,
covering data exploration, filtering/aggregation, joins, window functions, and business KPIs.

## Tools
SQL Server 2019 (SSMS)

## Files
- `01_exploration.sql` — data profiling, NULL checks, table relationships
- `02_filtering_aggregation.sql` — WHERE / GROUP BY / HAVING practice
- `03_joins.sql` — INNER/LEFT JOIN across Sales, Product, and Customer tables
- `04_window_functions.sql` — RANK, LAG/LEAD, running totals
- `05_kpis.sql` — YoY growth, AOV, customer retention, revenue concentration by territory
